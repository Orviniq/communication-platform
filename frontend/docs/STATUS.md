# Frontend status

The Android client's capability and release status is recorded here. The linked
contracts define required behavior. Live code and test fixtures were inspected at
`bcc64eba` (the Phase 1 step 1 commit). Evidence from older builds applies to the
revisions, devices, and scenarios stated in their run records.
